# LocalSoundsAPI User Manual

**Version 1.0**

---

A comprehensive, self-hosted audio production toolkit powered by AI.

Generate speech, clone voices, create music, produce sound effects, transcribe audio, build videos with subtitles, and chat with local or cloud LLMs -- all from a single web interface running on your own machine.

---

**Repository:** github.com/rookiemann/LocalSoundsAPI
